# SOIL
SOIL (Solid Object Imaging Library) is a wok-in-progress set of libraries which, in tandem, will create a highly modular, easy, system-agnostic and efficient way to render complex scenes with realistic lighting and to simulate collision physics.
Please note that this is a personal project and a work in progress. As such, I do not recommend using it for any actual projects as of right now. However, feedback is greatly appreciated!
## Bedrock Engine
The Bedrock Engine is the first piece of this project. Is is a graphics engine and input system capable of rendering multiple 3D models at once while handling any necessary keyboard/mouse inputs.
